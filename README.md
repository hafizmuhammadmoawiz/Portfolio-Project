# Moawiz Portfolio
React + TypeScript + Vite + Tailwind. `npm run build` → `dist`.
- Contact email, GitHub, LinkedIn, CV, profile photo: `src/config/site.ts` (or `VITE_CONTACT_EMAIL`)
- Projects / education / experience / certificates: `src/data/*`
- Replace `public/images/profile.svg`, add certificates to `public/certificates/`
- Update canonical URL in `index.html`, `public/robots.txt`, `public/sitemap.xml` before deploying.
